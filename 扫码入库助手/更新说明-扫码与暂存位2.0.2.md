# 扫码与暂存位优化版 2.0.2

## 本次更新

1. **收货记录编码修正**：记录查询 → 查看明细与差异 → 按采购单实收汇总，编码列优先显示商品编码（sku_id），不再优先显示国标条码（sku_code）。修改的是展示，不改历史数量。
2. **文字可复制**：业务文本支持鼠标拖选 / Ctrl+C；采购明细编码、条码旁各有「复制」按钮。取消鼠标按下时立即抢回扫码焦点，选择文字期间不再自动回焦。复制不触发收货或数量变更。
3. **采购明细字体加大**：商品编码17px、名称16px、条码15px、规格14px、数量16px，同时加大行间距。
4. **局域网配对二维码**：设置 → PDA局域网配对 → 生成5分钟一次性配对资料，显示二维码与原文本。全部本地生成，不上传第三方二维码服务。每台设备单独生成；二维码过期隐藏、配对后不可复用。
5. **暂存位置盘点**：电脑版和PDA均增加位置选择，支持全部位置（含暂存位）、正式仓位，以及页面实际支持的通用暂存位。预览和记录显示具体位置。
6. **采购单外商品收货**：本地商品资料能够找到的采购单外商品可扫码收货，保持独立商品行；桌面和PDA实收明细均有非采购单商品分隔提示。
7. **同码多商品选择**：合并采购单明细和本地商品库候选。两个不同商品编码即使一个在采购单内、另一个不在，也不会自动选第一个；国标码或辅助码重码会弹出选择。相同SKU的重复来源去重，不重复弹同一商品。

## 升级

- 先处理未核实操作，退出旧电脑版；私下备份旧EXE旁的完整data目录。
- 用包内「电脑端/扫码入库助手.exe」替换旧EXE，**保留原data目录，不要清空数据库**；勿同时运行两个版本操作同一库。新版启动前会做数据库升级备份。
- PDA安装「扫码入库PDA-2.0.2.apk」，保持原签名，可覆盖安装旧版。先结束/核实待处理请求再升级，不建议卸载清数据。进程重启后需重新配对。
- 到电脑设置检查所选货主/仓库公司的商品库，建议手动完成一次更新。开启自动同步后，主机运行、已登录时每6小时更新，失败保留旧快照。
- 普通收货扫码优先使用采购明细和本地资料，不为每次扫描强制调用商品API；盘点的实时库存查询不缓存。

## 配对二维码怎么用

1. 电脑与PDA接入同一可信局域网。电脑登录ERP，设置内选择实际局域网IP并启用PDA服务。
2. 点「生成5分钟一次性配对资料」，二维码显示在按钮下方。
3. PDA打开配对页，点进配对资料输入框，用**支持二维码的扫描枪，键盘输入模式 + Enter结束符**扫描电脑屏幕。回车后自动填入地址、证书指纹和配对码。
4. 核对主机和设备名称，点击安全配对。扫码只填资料，**不会自动授权连接**。
5. 若扫描枪不支持二维码或屏幕扫码，仍可复制整段资料，或手填地址、指纹、配对码。本版未加相机扫码和厂商专用SDK。

二维码相当于临时配对凭据，仅给受信设备看，不要截图公开分享。电脑必须保持运行、不要睡眠；不需要也不应开放公网端口。

## 通用暂存位盘点怎么用

1. 库存盘点 → 选具体货主和仓库公司（不能选所有商家/所有仓库）。
2. 选择主仓、进货仓、次品仓等实际附属仓，再把「盘点位置」设为「通用暂存位」。
3. 扫/输入完整商品编码或仓库条码，查询并明确选中一条库存明细。
4. 直接改数量，或用+1 / −1快捷填入增减值；预览原数量→目标数量，核对位置后确认。
5. **确认会直接修改ERP库存。** 只对所选库存明细操作，不合并不同位置，不创建不存在的库存记录。界面禁止操作的特殊位置仍禁止。
6. 提交前检查数量和位置未变；结果不明只回读核实，不自动重发。不要让多台终端同时修改同一明细，远端接口没有原子并发锁。

## 采购单外与重码

- 打开收货单时先明确货主/仓库公司，例如你实际使用的「品秀供应链—品秀刷货仓」，而不是所有商家。商品库按该范围使用，不跨货主乱找。
- 扫码命中多个不同SKU会列出编码、名称、条码及采购内/外标记；明确选择，再输入实收数量确认。
- 非采购单商品会在实收明细独立分组，但完全不在本地商品库的未知商品不会凭空创建。先更新资料，必要时才在设置显式启用联网兜底。
- 要把非采购单商品一并生成入库单，需关闭电脑「设置 → 校验采购单明细」。否则严格校验仍会阻止。
- 关闭后仍使用既有添加商品接口加入待入库单，再填实收数量并回读；不会修改原采购单、不会自动调用正式确认入库。

## 接口核实与测试边界

已通过用户现有登录浏览器进行只读核实，未用真实库存做写入验收：
- 商品资料 GetPageListV2 的辅助码字段是 _sku_codes，真实返回为多条逗号分隔字符串，例如 "6974445741559,6934713004441,6934713005516"；采购明细对应 sku_auxiliary_code。新版统一解析并兼容常见分隔符/数组结构。
- 通用暂存位由页面 GetDefaultPackId 读取真实位置ID，再加 [p].pack_id 精确筛选；同时保留货主、仓库公司与附属仓限制。长位置ID按字符串处理，不经过JavaScript浮点数。
- 委托仓返回行的co_id可能仍是登录公司；新版核对页面货主/授权仓上下文和登录公司，不把co_id误当作授权仓公司。

验收结果：
- 12套完整离线回归通过；新增12项覆盖辅助码、采购内外候选、候选伪造/过期防护、位置/移位校验、委托仓隔离、在线候选缓存隔离、一次性二维码等。
- 真实浏览器模拟接口验收通过：拖选后等待仍保留、编码/条码剪贴板内容、17px编码字体、汇总编码、重码选择、本地二维码实际解码、通用暂存位4→3、400px PDA采购外收货及分隔行，无JS错误。
- 最终EXE自检、临时库启动和资源验证；APK版本、嵌入资源一致性、v2/v3签名验证；发布包解压源码再次完整回归。
- **没有真实ERP新建入库/库存修改测试；新版APK未进行实体PDA扫描枪或模拟器点击验收。** 首次上线先小批量核对。旧版原生连接曾在Android12模拟器验证，不能替代本版实机验证。
