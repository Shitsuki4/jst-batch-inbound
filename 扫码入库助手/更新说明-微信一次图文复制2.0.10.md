# 扫码入库助手 2.0.10：微信一次图文复制

## 本次改动
- 保留两个按钮：**复制完整结果（含已收满）**、**仅复制差异**。
- 电脑端采用 Windows 原生富文本剪贴板：点击一次，再到本机微信粘贴一次，文字和结果图片一起进入输入框。无需来回复制两次；不自动点击发送。
- 文字包含采购单号、外部单号；已有入库单号时一并加入。图片同样包含这些单号。
- 入库单号来自本轮助手记录，空号和已拒绝记录排除，多个号码去重；不推断未关联的ERP单号，不表示ERP已确认入库。
- 删除原报告底部“本轮应收按开始时的ERP余量固定；本报告不是ERP入库确认凭证。”
- 结单和历史明细默认只显示差异，仍可切换全部；复制范围独立于当前显示筛选。

## 使用
1. 在**运行扫码入库助手的这台 Windows 电脑**打开结单或历史报告。
2. 按需要点击“复制完整结果（含已收满）”或“仅复制差异”。
3. 等到“已复制单号文字＋…图片”，去微信按一次 Ctrl+V，检查文字、图片和收件人后由你发送。

开发验证中，用户已确认图文一次粘贴正常。未代用户发送消息；发送后是否拆成文字一条、图片一条需在所用微信版本中确认，不承诺所有微信版本行为一致。

## 本机限制与失败处理
- 原生图文复制写入的是**运行助手的本机Windows剪贴板**，不是手机或另一台电脑。PDA接口不提供此操作，不会远程覆盖主机剪贴板。
- 未使用原生通道时保留浏览器兼容复制，并明确提示核对结果；浏览器多种MIME格式并不保证微信同时粘贴图文。
- 原生复制失败会明确提示，不会静默改成仅图或仅文字并声称成功。保存PNG及手动复制文字仅为备用。
- 图片从完整数据绘制，不截取滚动窗口。超过30000像素高度、8MB PNG或12MB请求会明确拒绝，不截断明细。
- 图片临时保存在 data/report-clipboard，每次复制使用独立文件；请粘贴后再清理缓存或移动软件目录。下次复制时只清理本模块生成且超过7天的PNG。
- 此功能不读取微信聊天、不操作联系人、不自动发送，也不调用ERP写入。

## 数量口径不变
- 本轮应收固定为开轮时采购数减开轮时ERP入库数，最小为0。
- 本轮已收为本轮所有物流单实收合计；刷新ERP不重算本轮应收。
- 开轮采购12、入库2：应收10。本轮收4、ERP刷新为6后仍是应收10、已收4、差6。
- 如果开轮就是采购10、入库6，本轮应收就是4。
- 编码、商品名、69码/辅助码及采购/入库展示不变。未知数量仍显示待核实。

- 退出旧电脑端，备份现有 data 文件夹，将新版电脑端EXE放回原位置运行，**保留原data**。
- PDA仍附原2.0.8 APK，签名与文件不变，**无需重装PDA**。
- 压缩包不包含任何实际数据库、登录信息、真实业务图片或Android签名材料。
