# 扫码入库助手 2.0.5 — 安卓6.0兼容、PDA下载二维码与登录修复

## 升级
1. 退出旧电脑端，备份旧程序旁的 data 文件夹。勿删除或用别处的 data 覆盖原数据。
2. 将本包“电脑端/扫码入库助手.exe”替换原 EXE（保持原 data 的相对位置），再启动。程序会执行升级前备份。
3. PDA 安装“PDA/扫码入库PDA-2.0.5.apk”。沿用原签名、版本号20005，可在已装2.0.x的设备覆盖升级。不要先卸载，以免清除本机待核对状态。
4. 未核对的收货请求请先核对；本次升级不会替你重发或确认业务单据。

## 无线下载安装
- 电脑和PDA连同一可信局域网。登录页面无需先登录即可点“PDA安装包下载二维码”；登录后也可在“设置”打开。
- 选择正确本机网卡，点“开启10分钟下载并生成二维码”，确认后用PDA浏览器扫码；也可将地址输入PDA浏览器。
- 该二维码只用于下载APK，不用于设备配对。安装后在电脑设置页另行生成配对二维码。
- HTTP下载服务默认关闭、10分钟过期，只提供此签名APK及下载说明，不提供账号、Cookie、收货或库存接口。不要公网映射。安装后可立即点“关闭下载服务”。
- 若被防火墙阻止，只按需允许可信专用局域网；不要关闭整个防火墙。也可USB传输本包中的APK。
- 系统若提示未知来源，只允许本次所需安装来源，安装后关闭该权限。

## 登录修复
- 扫码及“官方网页登录”采用每次独立Edge配置目录，通过CDP读取正在运行的浏览器内存Cookie，不再读取被占用/加密的Cookie数据库。
- 保持官方窗口打开，完成扫码、验证码或安全验证；应用会自动取回状态。不会结束用户其他Edge浏览器。
- 短信下发会保存会话Cookie，登录凭据绑定手机号、尾号和10分钟期限；使用后失效。缺少新登录身份时不借旧账号状态误报成功。
- 若官方要求安全验证、短信方式仍失败，请点击“官方网页登录”在官方页面完成。不会绕过验证码或网站的登录限制。

## 安卓6.0适配
- minSdk23（Android6.0），Android8专用API增加版本判断，JavaScript转译为ES5并包含必要polyfill，CSS变量静态展开。
- 包签名验证包含旧安卓需要的v1，以及v2/v3；沿用原签名。
- PDA业务连接仍走HTTPS和证书指纹校验，没有为兼容旧安卓取消证书验证。
