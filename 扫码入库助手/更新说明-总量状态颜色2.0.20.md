# 扫码入库助手 2.0.20 试用版

在已交付2.0.19基础上，仅修正采购总量对照的颜色显示，原有采购、实收、差异计算和初始快照规则不变。

## 总量表按状态显示整行颜色
- **绿色：收齐**，差异为0。
- **黄色：少收 / 多收**，保留负数/正数差额，并显示“少收”或“多收”文字。
- **灰色：采购单外 / 待核实**，用文字区分；数量不确定的商品不会显示为收齐。

实时采购总量表、初始采购单快照、采购单查询中的总量表使用相同颜色。修复鼠标悬停时底色被通用表格样式覆盖的问题；现在整行五个单元格都会保留对应底色，不只是小标签有色。

修改物流实收后，状态和颜色同步变化；例如从少收改为收齐，两张对照表同时从黄色变绿色。ERP采购数量修改后，实时总量按刷新后的数量着色；初始采购快照仍按固定采购量着色。

“仅显示差异”的原布局、颜色和本轮计算保持不变。完整复制图片继续保持绿/黄/灰底色，已验证本机接口传出的PNG和生成图片一致（模拟剪贴板，不操作真实微信）。

## 升级
1. 等待保存/生成结束，关闭旧服务。
2. 备份旧EXE和整个`data`文件夹。
3. 替换本包“电脑端/扫码入库助手.exe”，保留原`data`，不要新旧版同时操作同一数据目录。
4. 回滚恢复升级前EXE及整份`data`。

PDA仍为2.0.8，无需重装。本版不新增数据库结构，不改入库生成。2.0.19的固定初始快照、2.0.18的服务稳定性修复/入库双选/图标、2.0.17的暂存并对单全部保留。

旧记录首次采购数据缺失仍按2.0.19规则明确提示，不用实时数据冒充初始快照。实时指打开/查询/显式刷新时成功读取，不是后台推送。所有测试使用临时库和模拟ERP，没有操作真实ERP库存、价格或成本。
