# 差异配色与大字显示 2.0.11

## 本次变化
- 结单差异、历史“查看明细和差异”、采购单查询报告统一配色：收齐浅绿；少收、多收（含尚未扫码）浅黄；采购单外商品浅红；数量待核实浅灰。
- 填充整行背景，异常不只用一个小标签提示；同时保留文字差额，不能仅凭颜色判断。
- 商品编码、商品名称加大加粗；69码/条码、辅助码、采购/入库数量分层展示。
- 宽屏使用明细表；650px及以下使用商品卡片，三项数量在下方，不挤小字号。长编码和名称自动换行。
- 完整复制、仅复制差异的 PNG 使用同一配色；编码/名称28px、条码等24px、数量32px，行高按实际内容自动增长。图片仍是全数据生成，不截取滚动区域；超过30000px明确提示，不生成残缺图片。

## 原功能保持
- 默认仅差异、两个复制按钮、采购单号/外部单号/已有入库单号、一次复制一次粘贴方式不变。
- 本轮应收仍是开轮时采购数减当时ERP入库数，最小为0；刷新不重算。开轮12/2，应收10；本轮收4，再刷新ERP入库6后，仍是应收10、已收4、还差6。
- 没有修改入库生成、库存或本地实收计算，也没有更换PDA APK。

## 升级
关闭旧电脑端程序后替换电脑端EXE，保留原 data 文件夹；PDA沿用2.0.8，无需重装。
