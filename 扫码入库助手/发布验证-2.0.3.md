# 2.0.3 发布验证

版本：电脑端 2.0.3-inventory-wire；兼容 PDA 2.0.2（APK 不变，本热修复包不重复附带）。

## 已通过的检查

- 12 套隔离回归全部通过：smoke、batch-flow-http、po-items-http、inventory-unit、inventory-http、catalog、scan-ux、pda-backup、inbound-unit、inbound-http、existing-features、batch-flow-unit。
- inventory-unit 共 36 项，包含真实 JstClient.callback HTTP 表单参数检查；验证 Args[0] 是 JSON 字符串，覆盖整数、小数及目标数量；模拟 ERP 拒绝旧数组格式。
- 浏览器模拟回归：原生文字选择/复制、采购明细大字体、汇总商品编码、采购内外同码弹窗、二维码离线解码、通用暂存位 -1、PDA 采购外商品候选与收货；无页面 JavaScript 错误。
- 打包 EXE：TLS/二维码自检、首次升级备份、设置持久化、内置页面资源一致性、辅助码查询、按实收预览及未登录请求拒绝。
- EXE 字节码检查：实际打进 EXE 的 inventory、jst、inbound、codes、backup 与发布源码编译结果一致；从 EXE 加载代码，在禁止联网下验证 +1/-1 对应目标数、直接改数量、零和小数的 HTTP 序列化。
- 旧 2.0.2 ZIP 和 APK 的 SHA256 未改变；旧 APK 内置 PDA 页面与当前主机前端源码一致。

## 发布包交付校验

发布脚本使用文件白名单，随包 manifest-sha256.json 记录每个文件的大小与 SHA256。交付前通过 verify_inventory_wire_release.py 解压到独立临时目录，检查无额外文件/隐私目录、逐个验证哈希、检查 EXE 与解压源码一致，并对解压源码再次运行 12 套回归。任一检查失败都停止交付。

不包含用户 data、浏览器登录资料、ERP 会话、真实测试审计数据库、抓包、APK 私钥。
