# 2.0.1 · 入库明细校验开关与采购单外商品

## 怎么使用
1. 电脑端打开「设置 → 校验采购单明细」。默认开启，保持旧版规则。
2. 要把采购单外实收商品加入入库单，选择「关闭（不校验，允许添加采购单外商品）」并点「保存」。
3. 重新打开「按实收生成入库单」，选仓库、核对货主和实收。预览会标出「采购单外商品 · 添加商品」及当前校验状态。
4. 确认生成：从原采购单创建待入库草稿，使用「添加商品」接口加入实收SKU，再把默认数量改为本次实收绝对数量并回读核对。不会把整张采购单应收数量带入，也不会给采购单补商品。
5. 到聚水潭核对商品编码、仓库、数量、成本价，再自行确认正式入库。

## 开关影响范围
- **开启**：本地未匹配采购单的商品不能生成；写入前读取最新采购单，要求每个实收SKU恰好匹配一条采购明细。
- **关闭**：不要求实收商品属于采购单、不做上述采购明细逐行比对；缺少的草稿商品按编码走 AddItems（添加商品），已有的商品不重复添加。
- 无论开关状态如何，都只处理未生成物流子批次的正数实收；同SKU按实收合并，零数量忽略。
- 无论开关状态如何，货主/仓库公司、采购单来源、所选仓库、单据状态、编码/数量合法性、重复请求、回读数量核对都仍保留。关闭的是本程序的采购明细匹配检查，**不是绕过ERP权限或业务规则**；ERP拒绝的商品不能强行添加。
- 未识别条码请先同步商品库，确认是正确的商品编码再生成。本程序不会新建ERP商品资料，也不会伪造采购价；采购单外商品的成本由ERP处理，需人工确认。
- 设置属于电脑主机，PDA共用；PDA不开放远程修改桌面设置的权限。

## 修改设置与原单续作
- 校验模式和仓库、实收一起固定到确认快照及指纹中。预览后改设置须重新预览，旧确认不能偷偷按新模式写入。
- 已取得单号的原单继续使用原快照设置；切换开关不会重建单据或解锁已生成的物流明细。生成记录显示本单原校验状态。
- 添加成功但响应丢失：只继续原单，重新读明细后补齐缺失商品、覆写绝对数量，不重复添加。创建结果未知时仍需核实并关联原单，不能自动重建。

## 升级
- 先停用PDA，关闭电脑端，备份原data文件夹；用「电脑端/扫码入库助手.exe」替换原EXE并保留同目录data和导出。不要覆盖业务库。
- 安装配套「扫码入库PDA-2.0.1.apk」（版本号20001，同原包名和签名，可覆盖安装），重新配对。旧2.0.0 APK仍由主机执行新规则，但不能显示新的模式/外部商品提示，建议一并升级。
- 未新增业务表或删除旧数据；老入库快照没有校验字段时按原开启规则处理。
- Windows主机仍需运行并登录，PDA为局域网伴随端，不支持离线ERP写入。
