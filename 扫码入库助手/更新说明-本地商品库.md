# 商品资料本地缓存版（2026-10-01）

## 本次已交付

- 首次登录后自动后台分页同步可用货主、当前收货货主的商品档案，此后每 6 小时检查更新；程序启动后约一分钟内检查一次。
- 同步基础资料：商品编码、款式编码、名称、规格、国标条码、辅助码、单位、状态和图片地址。不包含实时库存，也不下载图片文件。
- 扫码优先匹配本地采购明细，再查本地商品资料；同条码多商品保留人工选择，不任取第一条。
- 默认关闭“缺码实时联网”：未识别时提示更新资料或核对，若继续确认则记为差异，不计为匹配实收。
- 后台分页下载不占用收货写入锁。全量成功后原子替换；失败保留旧快照，5 分钟后重试。
- 按登录公司、货主和仓储公司隔离商品库，避免同码串货主；扫码确认期间资料变更会要求重新扫描。
- 设置页显示各货主商品数、上次成功时间和错误，可点击“立即更新商品资料”。
- 修复入库单回读默认只查主仓的问题：查不到时会按附属仓字典逐仓查找，支持核对进货仓/次品仓中的原单。

## 附属仓选择现已补齐

本次选仓入库与库存盘点版已通过实际操作抓包确认 Save 换仓流程，并实现选择附属仓及回读核验。
不使用列表 wh_id 过滤条件冒充换仓；详见《更新说明-选仓入库与库存盘点.md》。

## 使用

1. 保持原账号、货主和仓储公司选择正确，登录聚水潭。
2. 到“设置 → 本地商品资料”，等待首次同步完成；也可点“立即更新商品资料”。
3. 默认按本地库扫码，缺码先更新资料；如确有需要，可打开“本地缺码时实时联网”，再点击参数区“保存”。开启后缺码查询仍可能等待网络。
4. 程序关闭、电脑休眠或退出登录时不进行后台拉取；重新运行并登录后补做已过期更新。这不是独立 Windows 定时服务。
5. 网络断开时仍可使用已有采购明细和旧商品快照收货，但不能新拉采购单或向聚水潭生成入库单；图片加载也需要网络。
6. 商品档案是识别辅助，不代表当前库存、最新价格或入库权限。正式入库仍须核对聚水潭单据。

## 升级

关闭旧程序，备份原程序旁完整 data 文件夹。将本包 dist/扫码入库助手.exe 放回原 EXE 路径替换，不覆盖原 data 和导出文件夹。
首次启动会在 data 下新增 catalog.db；与 jst.db 收货库分开，原收货明细不清空。
源码版在项目目录运行 python app/server.py，仍只依赖标准库。
