# 扫码入库助手 2.0.15 · 差异数量独立格 / 扫码忽略禁用商品

## 本次改动
### 差异数量放到右侧独立格
- 左侧少收商品：商品名称、编码、应收/实收在左，少收数量单独在右侧格子。
- 右侧多收/采购单外商品：信息在左，多收或单外实收数量单独在右侧格子。
- 一对多对照时，左边商品格与少收数量格一起跨行，右边每个商品各自保留数量。
- 采购单外的信息格和数量格都为灰色；采购内数量差异黄色；已匹配绿色。
- 正式页面与复制/导出图片同步调整。相似配对规则、SKU核对、数量及入库逻辑不变。

### 设置 → 扫码忽略禁用商品（默认开启）
- 依据当前货主商品资料中的启用状态；不是名称、编码大小写，也不是采购单中有没有该SKU。
- 开启后，状态禁用的商品不参与扫码解析，不出现在候选弹窗中。条码、辅助码以及直接扫码商品编码共用此规则。
- 排除禁用品后只剩一个商品就直接选择；多个仍需选择；全部禁用只提示未登记，不回退为未知商品入账。
- 关闭后恢复原候选选择方式。保存后立即生效，普通收货、无采购单登记及连接本电脑的PDA收货共用。
- 缺失/无法识别的状态保留候选，不猜测为启用或禁用；人工选择提交时再次校验，不能通过旧弹窗选中刚被禁用的商品。
- ERP商品状态变更后，请在电脑设置的商品资料区域更新本地商品库。本版按当前本地资料判断，不会每扫一次访问ERP。
- 本地资料观察到的 enabled=1 / -1 分别支持启用 / 禁用；同时兼容明确布尔和文字标志。不会硬编码PT62、PT25的状态。
- 只影响新扫码候选，不删除历史实收、不改采购单、不修改ERP商品启用状态。

## 升级
1. 退出旧助手，备份旧EXE与整个data文件夹。
2. 将本包“电脑端/扫码入库助手.exe”放入原程序目录替换旧EXE，保留data，不覆盖或删除data。
3. 启动后程序先进行升级前备份。在设置中确认“扫码忽略禁用商品”开关并保存。
4. PDA仍是2.0.8，无需重装；连接已升级的电脑后使用同一服务端过滤规则。

## 保持不变的边界
采购单三状态和提醒逻辑、跨来源防重建保护与2.0.14一致，详见附带2.0.14说明。
只生成待入库草稿，不确认库存，不写价格/成本/供应商。真实ERP的采购成本继承、完成状态、修改时间字段仍需用户试用核实。
本版使用隔离数据库和假ERP做功能验证，未在真实ERP创建单据、改单或确认入库。
包内无账号、Cookie、密钥、用户数据库或商品资料库。截图使用隔离测试数据运行正式页面获得。
