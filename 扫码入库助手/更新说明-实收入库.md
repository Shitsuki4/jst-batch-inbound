# 实收入库版更新说明

## 新增功能
- 收货页、采购单记录、最近记录增加“按实收生成入库单”入口。
- 生成前预览商品、实收数量、物流单号；相同商品汇总，只计尚未生成的实收。
- 使用聚水潭采购单创建“待入库”单，写入实际收货数量并回读核对。
- 保存入库单号及确认快照；重复点击不会重新建单。
- 已取得单号后网络中断，可继续完成同一张单；创建结果不明时禁止自动重建。
- 对已关联的本地物流子批次/明细加锁，防止改数后与聚水潭不一致；新物流子批次可继续补收。
- 不自动确认入库，不修改商品价格；新版支持在原货主和仓库公司上下文中选择入库仓库，采购关联仍来自原采购单。

## 安装/升级
1. 先关闭旧程序，备份原程序旁完整的 `data` 文件夹。
2. 包内 `电脑端/扫码入库助手.exe` 是重新编译的免 Python 版。
3. 用它替换原 exe，**保持原来的放置路径**，不覆盖旧 `data` 和 `导出`。
   如果把 exe 换到新目录，也必须将原 `data` 一并复制，否则看到的将是一个新空库。
4. 首次启动自动新增入库日志表，不清空旧收货记录。
5. 源码用户也可运行 `python app/server.py`；运行前请安装 `requirements.txt` 中依赖（含PDA证书所需cryptography）。

## 实收口径
一个收货批次对应一张本地采购单收货记录，下方包含多个物流子批次。
每次生成汇总其中尚未生成且有正数实收的物流子批次；零数量不计，已生成数量不重复计。
若之后继续补收，使用新物流子批次，下次只生成新增部分。
2.0.1起可在设置切换「校验采购单明细」（默认开启）。开启时未匹配商品、采购单同SKU多行等会阻止开单；关闭时允许采购单外商品经「添加商品」加入入库草稿。非法数量始终阻止，远端数量回读核对始终保留。
上游如保留未实收商品的零数量行，保持为零，正式入库前请在聚水潭核对/清理。

## 请注意
- 这是“生成待入库单”，不是“确认入库”。以聚水潭后台实际状态为准。
- 首次使用请小批测试，核对商品、数量、仓库和成本后再在聚水潭确认入库。
- 页面显示“待核实”时，不要删除本地数据、不要另建单。先按采购单查聚水潭原单，再关联原单号。
- 本次验证为离线模拟 ERP 接口、HTTP 并发及浏览器验收，未向真实聚水潭创建测试单。
