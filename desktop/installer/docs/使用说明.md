# 收货小助手 4.1.3 离线完整安装版

“完整”指运行依赖随安装包一起提供，不代表业务已经全部重写为 .NET。本版仍是
.NET 10/WPF 宿主 + 原 Python 打包后端 + WebView2 业务界面 + FFmpeg 独立录像进程。

## 安装与首次运行

1. 双击 `收货小助手-4.1.3-离线完整安装程序.exe` 安装。当前用户安装，不需要管理员权限。
2. 安装后从开始菜单或桌面快捷方式启动。启动时会自动检查内置的 WebView2 与 FFmpeg/ffprobe，
   不需要联网下载，也不需要 `winget`。
3. 进入录像设置，枚举并选择本机摄像头，选择录像目录，建议先用 720p/30fps 测试。
4. 启动软件时默认打开监控浮窗，并默认启用“扫描物流单号自动录像”。如果用户在设置中明确关闭，
   该开关会写入 `native-settings.json`，之后重启仍保持关闭。
5. 未配置磁盘预警 GB 和停止 GB 时不会开始录像；请在视频设置里显式保存这两个阈值。

## 数据位置与卸载

- 业务数据、设置、浏览器登录资料：`%LOCALAPPDATA%\ReceivingAssistant\v3`。
- 默认录像目录也在该目录下，可以在软件中改到其他磁盘。
- 导出的 Excel/CSV 文件在安装目录下的 `backend\导出`。
- 安装程序只安装程序文件，不导入旧版 2.0.21 的账号或 data。

### 卸载

从开始菜单打开“卸载收货小助手”（或在 Windows“设置 › 应用”里卸载“收货小助手”），会先让你选择怎么处理数据：

- **保留全部数据**（默认，推荐）：只删除程序，重新安装后继续使用原有收货记录、录像和设置。
- **自定义**：勾选要保留的类别，未勾选的会被删除。可选类别（只列出本机实际存在的，并显示大约占用空间）：
  - 收货数据库与自动备份：收货记录、对单 / 联合收货 / 采购监控数据、业务设置（`v3\data\*.db`、`v3\data\backups`）
  - 录像文件：默认录像目录 `v3\录像`
  - 导出文件：安装目录 `backend\导出`
  - 本机设置与登录记忆：录像 / 界面设置、保持登录凭据、扫码登录浏览器资料、PDA 配对证书
  - 缓存与日志：浏览器缓存、提示音、运行日志，可自动重建
- **完全卸载**：删除整个 `%LOCALAPPDATA%\ReceivingAssistant\v3` 和安装目录内的导出文件，**无法恢复**。
  会再弹一次确认并列出将删除的内容；录像如果还可能用于售后举证，请先复制到其他磁盘备份。

注意：

- 如果在软件里把录像目录改到了其他位置，那里的录像**任何选项都不会删除**。
- “收货小助手运行依赖”（`%LOCALAPPDATA%\ReceivingAssistant\runtime`）是独立程序，不会被删除，需要时在“设置 › 应用”里单独卸载。
- 小助手还在运行时，卸载程序会列出正在运行的进程，可以选“强制结束并继续卸载”或“取消”。
  强制结束会中断正在进行的 ERP 提交和录像：卸载后请到聚水潭核对入库单，未保存的录像片段会丢失。
  更稳妥的做法是先在小助手里结束录像、等提交完成后正常退出，再卸载。
- 命令行静默卸载（`unins000.exe /VERYSILENT`）默认保留全部数据；小助手在运行时会拒绝卸载。
  加 `/FORCECLOSE` 强制结束安装目录内的小助手进程后继续，加 `/PURGEDATA` 删除全部数据。

## 备份恢复

在 设置 →「安全备份」卡片中操作：

1. 点击「刷新备份列表」，列表会标明类型：手动备份、每日自动、升级前自动、恢复前自动备份。也可点「从文件夹恢复」/「从压缩包恢复」选择复制到其他硬盘的备份。
2. 点击「预览」：显示备份与当前数据的行数对比。如果出现红色警告，表示当前已生成的部分入库单（列出 ERP 入库单号）不在备份中——恢复后本软件不再知道它们已入库，**有重复入库风险**，恢复后请先在聚水潭核对，不要重复提交。
3. 在确认框输入「恢复」两字，点击「恢复所选备份」。软件会先自动做一份「恢复前自动备份」，再校验所选备份；替换在下次启动时进行，任何一步失败都会自动回滚到恢复前的数据。
4. 桌面版会安全退出（结束录像、停止业务服务）并自动重新打开；在普通浏览器中操作时，请关闭后重新打开收货小助手。重新打开后页面顶部会显示一次恢复结果。
5. 等待重启期间可点「取消待恢复」，当前数据不变。

限制：正在录像、有未完成的入库、正在提交或结果未知的盘点 / PDA请求、PDA服务运行中时不能恢复，请先处理。恢复只替换收货数据库，不影响录像文件、ERP登录资料和PDA密钥。

注意：旧录像按「来源:批次ID」关联。恢复较早的数据后，之后新建的批次可能重新用到相同的批次ID，旧录像可能显示在这些新批次下；售后举证时请以录像里的物流单号、时间和画面为准核对。

## 功能与限制

- 保留普通收货、无采购单收货、多采购单联合收货与汇总对单等原有业务。
- 普通收货扫到的新物流单号若已在「无采购单收货」登记且尚未绑定采购单（或已绑定本采购单），会先弹窗提示：选「去无采购单绑定」打开该登记（本单不会多出空的物流子批次），选「仍在此处收货」则继续收货，本次打开期间同一单号不再提示。PDA 扫物流单号照常建立子批次，只显示提示文字。
- 监控浮窗可移动、缩放、置顶，可结束录像或继续本单新一段。
- 启用自动录像后，确认物流单号开始录制，切换物流单号结束上一段；商品扫码不切段。
  换段存在间隔，必须看到“正在录制”后再拆包，且切段不是无缝录像。
- 精细 CSV 导出支持时间、采购单、外部单号、物流单号、商品编码包含条件，扫码流水精确到秒。
- 扫码记录按扫码时间与录像首帧时间对齐（精确到秒），不是视频 PTS 级定位；未实现 PDA USB 录像联动、无缝切段，也未做 48 小时长稳验证。
- 截图是 480×270 预览，不等于高清视频帧。

## 操作记录（电脑 / PDA 审计日志）

- 「操作记录」页记录谁（电脑或哪台 PDA、当前 ERP 账号）在什么时间做了什么：扫码加数、修改数量、删除明细、物流单号新增 / 修改 / 删除、复制上一单、挂起 / 继续 / 结单 / 删除收货单、关联采购单、入库请求与结果（失败也会记录原因）、登录 / 退出 / 切换账号、修改设置、启停或撤销 PDA、库存修改、手动备份等。数量类操作同时记录操作前和操作后的数量。
- 可按时间、设备、操作类型、采购单号、SKU / 条码筛选，每页 50 条；在收货明细弹窗点「查看此单操作记录」可只看该单。
- 「导出 CSV」按当前筛选导出（单次最多 5000 条）。
- 默认保留 **180 天**，可在本页修改为 7–3650 天，超期记录自动清理。记录单独保存在 `data\operation_log.db`，随自动备份一起备份。
- **不记录**密码、Cookie、短信 / 图形验证码、PDA 配对码或令牌。记录写入失败只会在日志中提示，不影响收货、入库等业务操作。
## 未知条码学习

- 扫到商品资料查不到的条码时，可在弹框里搜索并确认对应商品，「学习」后此码按该商品识别，明细上标「学习匹配」；也可点「跳过」，不登记任何数量。
- 商品资料始终优先：只有当前货主 / 分仓的商品资料和采购明细都查不到此码时，才使用学习记录兜底；已能识别的条码、已禁用的商品不能学习。
- 学习记录按当前登录公司 + 货主 + 仓储共享，换公司或换货主 / 分仓不会互相使用。
- 之后商品资料里出现了此码：对应同一商品则记为「已被商品资料覆盖」；对应其他商品则「冲突已停用」并提示一次。两种情况都以商品资料为准，之后不会自动恢复使用学习记录；需要时请删除后重新学习。
- 设置 →「商品资料」→「已学习条码」可查看状态、搜索、删除和导出 CSV。

## 远程管理页（IPv6，默认关闭）

- 在「设置 → 远程管理页」设置端口（默认 18443）、管理员用户名和至少 10 位密码，勾选启用并保存后，可用手机 / 电脑浏览器打开设置页显示的 `https://[IPv6地址]:端口/`，**只读**查看收货历史和录像（在线播放；下载默认关闭）。
- 需要：本机有公网 IPv6；点击设置页按钮添加 Windows 防火墙放行规则（需管理员确认）；光猫 / 路由器允许 IPv6 入站。
- 浏览器会提示证书不受信任，请核对证书 SHA-256 指纹与设置页一致后再继续。远程页面不能收货、入库、删除或修改设置；登录和观看录像记录在 `data\logs\remote-access.log`。不用时请关闭。

## 软件更新

- 在「设置 → 软件更新」查看当前版本与最新版本、更新说明，点「检查更新」立即检查，点「下载并安装」下载、校验并安装；「打开发布页」可在浏览器手动下载。
- 两个下载渠道：**GitHub 原链接**，以及国内网络较慢时使用的**加速站 gh-proxy.com**。下载失败时页面会提示切换另一个渠道重试；中断的下载会保留已下载部分，下次继续。
- 默认每天自动检查一次（只检查、不自动下载），可在设置中关闭。发现新版本时窗口顶部出现提示，每个版本关闭一次后不再提示。
- 安全：无论哪个渠道，下载的文件都按发布页 `SHA256SUMS.txt` 校验 SHA256，不一致即丢弃；安装前再复核一次。
- 正在录像、入库提交中，或有未保存的待录入商品 / 设置草稿时，不能安装更新，请先完成或结束。安装前程序会安全退出。
- 安装版：运行新版安装程序覆盖升级，数据保留。便携版：新版本解压到当前文件夹旁边的**新文件夹**，程序退出后自动打开该文件夹，请从新文件夹启动；旧文件夹中的数据**不会自动迁移**，如需沿用请手动复制 `data` 目录。

## 录像查询

- 在业务界面打开“录像查询”：默认显示今天的录像。搜索框可直接扫物流单号，也可输入采购单号、外部单号、商品编码或备注，回车即查；单号不在当前日期范围时会自动切换到“全部”。
- 列表可按住 Ctrl / Shift 多选，或勾选第一列；表头复选框全选当前列表。点列标题排序。
- 双击一行在右侧播放器播放，可倍速、拖动、全屏（Esc 退出）。播放器下方的扫码记录点击后跳到该时间点（需要业务服务正在运行）。截图和导出片段使用内置 FFmpeg，导出不重新编码，起点会对齐到之前最近的关键帧（约 1 秒内）。
- 删除所选前会列出将删除和跳过的录像：正在录制的始终跳过；售后保护的默认跳过，需在确认框勾选“同时删除售后保护片段”。删除不可撤销。
- 清理旧录像：选择 90 天或 180 天，点“选出旧录像”只会选中超龄、已完成、未保护的录像，核对后再点“删除所选”。

## 安全与签名

- 安装包尚未做商业代码签名，Windows 可能提示“未知发布者”。不要关闭系统安全防护。
- 内置 WebView2 为固定版本，不会自动升级；其安全更新需要随新版安装包发布。
- 组件损坏时重新运行同一个安装包即可修复，不需要联网安装系统依赖。
