收货小助手 3.0.2 · 离线完整安装版

收货 / 对单 / 视频举证

运行依赖已经随软件提供（.NET、Python、FFmpeg/ffprobe、WebView2 固定运行时），安装和启动不需要联网下载这些组件；ERP 业务本身仍然需要网络。

业务数据、设置和浏览器登录资料保存在当前用户的 %LOCALAPPDATA%\ReceivingAssistant\v3，录像默认也在该目录下，可以在软件里改到其他磁盘。

卸载：开始菜单 →“卸载收货小助手”。可以选择保留全部数据（默认）、自定义保留哪些（收货数据库、录像、导出文件、设置与登录记忆、缓存日志），或完全卸载删除所有数据（无法恢复，请先备份录像）。小助手还在运行时可以选择强制结束后继续卸载，但会中断正在进行的 ERP 提交和录像。独立的“运行依赖”不会被删除，需单独卸载。

不要用本安装包覆盖旧版 2.0.21 的 data 目录。升级前先关闭软件、核实没有未提交的入库单并备份数据。

详细功能范围与使用步骤见同目录的 使用说明.md；第三方组件许可见 THIRD-PARTY.md。
